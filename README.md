# Submission Instructions

When your assessment is complete, submit it by sharing a GitHub repository with us.

## Required Submission Format

Your completed assessment must be submitted as a **GitHub repository**.

Do **not** submit:

* ZIP files
* Google Drive folders
* Email attachments
* Code snippets
* Screenshots only

## Repository Requirements

Your GitHub repository must include:

* Frontend source code
* Backend source code
* Docker setup
* Mock data file
* README with setup instructions
* README with API endpoint summary
* README with AI Tool Usage section
* README with known limitations or tradeoffs
* README with walkthrough video link

## How to Submit

1. Create a new GitHub repository for your solution.
2. Push your completed code to that repository.
3. Make sure the repository is accessible.
4. Share the repository with the GitHub user:

```text
sbpsynth
```

5. After sharing the repository, notify us that the assessment has been submitted.

## GitHub Sharing Requirement

You must give repository access to:

```text
sbpsynth
```

If the repository is private, make sure this user has access.

If the repository is public, still mention the repository URL clearly in your submission message.

## Final Submission Checklist

Before submitting, confirm that:

* `docker compose up --build` runs the project successfully
* Frontend is available at `http://localhost:5173`
* Backend API is available at `http://localhost:8000`
* API docs are available at `http://localhost:8000/docs`
* CRUD functionality works
* README includes setup instructions
* README includes AI Tool Usage
* README includes video walkthrough link
* No secrets, credentials, API keys, or private data are included
* Repository is shared with `sbpsynth`
